## someMaths

**M1.** If `p` is the chance one random sample is good enough,
what is the chance that `n` samples ALL miss? So what is the
chance at least one hits?

**M2.** In `p = 0.35 / 6`, where does the 0.35 come from, and
where does the 6 come from?

**M3.** Roughly how many random samples give 95% confidence of
landing in that top slice? (One number.)

**M4.** Team A pays 50 labels; team B pays about 6. What is
team B doing that makes it exponentially cheaper?

**M5.** Name two of the three "heroic assumptions" behind the
algebra — and say what checked the number anyway.

## Lua-101

**Q1.** What does `#t` return for `t = {10,20,30}`? For
`t = {}`?

**Q2.** Lua has one data structure. Name it. What does it
replace from Python (name three things)?

**Q3.** Predict the output:

```lua
if 0 then print("yes") else print("no") end
```

Why does the same test print differently in Python?

**Q4.** What is the difference between `pairs(t)` and
`ipairs(t)`? Which one stops at the first `nil`?

**Q5.** In `function rand(lo,hi,    x)` — what is `x`? Why is
it after the wide gap, and what would break if a caller passed
three arguments?

**Q6.** Predict the output:

```lua
local a = {1,2,3}
local b = a
b[1] = 100
print(a[1])
```

One sentence: why?

**Q7.** `x = 5` inside a function, no `local`. Where does `x`
live? Why is that the most dangerous default in Lua?

**Q8.** What do these print?

```lua
print(nil == false)
print(nil and 1 or 2)
```

**Q9.** `t.mid(t)` and `t:mid()` — same or different? What
does the colon do?

**Q10.** Predict the output, then name the feature:

```lua
local function counter(    n)
  n = 0
  return function() n = n + 1; return n end end
local c = counter()
print(c(), c(), c())
```

## Answers

**I1.** experts are slow (hours for a handful); historical
labels unreliable (90% of "false positives" wrong); real
oracles ruinous (x264: 11 params, 1,000+ hours).
**I2.** `-` minimize goal, `+` maximize goal; neither = an
input (x) column.
**I3.** can't inspect it; changes without notice; confidently
wrong so every output needs a check; each generation costs
more (any one).

**M1.** `(1-p)^n`; at least one hit: `C = 1-(1-p)^n`.
**M2.** 0.35 = Cohen's negligible difference (in sd units);
6 = the ±3 sd width of a bell curve.
**M3.** ~50 (`log(0.05)/log(0.9417) = 49.8`).
**M4.** chopping a ranked list — halving, so `log2(50) ≈ 6`.
**M5.** one dimension, bell curve, independent draws; checked
by 100,000 runs over 127 MOOT tasks (flat at 95 above
budget≈50, check≈5).

**Q1.** 3 and 0.
**Q2.** the table; lists, dicts, objects.
**Q3.** "yes" — only `nil` and `false` are falsy in Lua;
Python's 0 is falsy.
**Q4.** `pairs` walks all keys in any order; `ipairs` walks
1..n and stops at the first `nil`.
**Q5.** a local, not an argument (reading-aid convention); a
third argument would silently land in `x`.
**Q6.** 100 — tables are references, not copies.
**Q7.** a global; typos silently create globals instead of
erroring.
**Q8.** `false`, then `2`.
**Q9.** same; the colon passes the receiver as a hidden first
argument (`i`).
**Q10.** `1 2 3`; a closure capturing `n`.
